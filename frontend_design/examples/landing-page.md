# Landing Page Design Example

## Goal

Drive one primary action.

---

## Structure

```text
Navbar
Hero
Problem
Solution
Features
Demonstration
Benefits
Social Proof
Pricing / Offer
FAQ
Final CTA
Footer
```

Do not blindly use every section.

---

## Hero

Structure:

```text
Eyebrow
Headline
Supporting text
Primary CTA
Secondary CTA
Visual
```

---

## Section Rhythm

Do not make every section look identical.

Create rhythm through:

```text
Typography
Background changes
Layout changes
Image placement
Grid changes
Whitespace
```

---

## Animation

Use motion to guide attention.

Good:

```text
Hero entrance
Product demo
Scroll reveal
CTA hover
Image transition
```

Avoid:

```text
Infinite animation everywhere
```

---

## CTA

The primary CTA should remain visually recognizable.

Use consistent CTA wording throughout the page.

---

## Final Test

Ask:

```text
Can a visitor understand the product quickly?
Is the primary action obvious?
Does each section have a purpose?
Does the page feel like one coherent brand?
```
