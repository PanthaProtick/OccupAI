# Dashboard Design Example

## Goal

Help users understand and manipulate information quickly.

---

## Structure

```text
Sidebar
Top navigation
Page heading
Filters
Key metrics
Primary visualization
Secondary visualization
Data table
```

---

## Density

Dashboards can be information-dense.

However:

```text
Dense ≠ cluttered
```

Use:

* Whitespace
* Alignment
* Grouping
* Typography hierarchy

---

## Cards

Use cards only where they help group information.

Do not turn:

```text
Every metric
Every chart
Every paragraph
```

into separate decorative cards.

---

## Charts

Use appropriate chart types.

```text
Trend → Line
Comparison → Bar
Distribution → Histogram
Composition → Stacked / appropriate chart
Single KPI → Metric
```

Do not use decorative charts that communicate no useful information.

---

## Animation

Use restrained motion:

```text
Chart entrance
Value update
Hover tooltip
Filter transition
```

Avoid distracting animated dashboards.

---

## Responsive

On mobile:

```text
Sidebar → drawer
Columns → stack
Wide table → horizontal scroll or transformation
```

Preserve the most important information.
