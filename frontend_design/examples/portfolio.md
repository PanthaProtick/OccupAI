# Portfolio Design Example

## Goal

Create a portfolio that communicates the person's identity and work within seconds.

---

## Recommended Structure

```text
Navbar
↓
Hero
↓
Selected Projects
↓
Project Case Studies
↓
Experience
↓
Skills
↓
About
↓
Contact
↓
Footer
```

---

## Hero

Include:

```text
Name
Role
Short positioning statement
Primary CTA
Secondary CTA
Optional visual
```

Avoid generic:

> "Welcome to my portfolio."

Prefer a specific positioning statement.

---

## Project Section

Each project should communicate:

```text
Project name
What it does
Technology
Result / purpose
Visual
Link
```

Use strong project imagery.

---

## Visual Directions

### Developer

```text
Clean
Technical
Minimal
Dark/light neutral
Monospace accents
```

### Creative

```text
Large typography
Asymmetric layout
Strong imagery
Motion
```

### Editorial

```text
Serif display
Whitespace
Strong typography
Image-led layout
```

---

## Animation

Use:

```text
Project hover
Image reveal
Subtle text reveal
Scroll transitions
```

Avoid animating every text block.

---

## Important Rule

The projects are the product.

Do not allow decorative effects to dominate the portfolio.
