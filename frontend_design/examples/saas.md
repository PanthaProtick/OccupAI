# SaaS Design Example

## Goal

Communicate the product's value and drive conversion.

---

## Structure

```text
Navbar
Hero
Product visualization
Problem
Solution
Features
How it works
Social proof
Pricing
FAQ
Final CTA
Footer
```

---

## Hero

Must answer:

```text
What is it?
Who is it for?
Why should I care?
What should I do?
```

---

## Product Visual

Prefer:

```text
Actual UI
Product screenshot
Interactive demo
Workflow illustration
```

Avoid random decorative imagery.

---

## Color

Usually:

```text
Neutral foundation
+
Strong brand accent
+
Semantic colors
```

---

## Animation

Good:

```text
UI demonstrations
Subtle entrance
Hover feedback
Product state transitions
```

Avoid excessive background animation.

---

## Conversion

Use clear CTA hierarchy.

Primary:

```text
Start Free
Get Started
Book Demo
```

Secondary:

```text
View Demo
Learn More
```

---

## Trust

Consider:

```text
Customer logos
Metrics
Testimonials
Security information
Integrations
```

Only include real or clearly marked placeholder content.
