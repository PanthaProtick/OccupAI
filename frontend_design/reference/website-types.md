# Website Type Design Reference

## Purpose

Use this file to choose visual direction and UX priorities according to the type of website being built.

---

# Portfolio

## Priorities

```text
Identity
Projects
Experience
Skills
About
Contact
```

## Good styles

```text
Editorial
Minimal
Creative
Experimental
Developer-focused
```

## Animation

Good:

* Project hover
* Image transitions
* Text reveal
* Page transitions
* Scroll storytelling

Avoid excessive effects that hide the work.

---

# SaaS

## Priorities

```text
Value proposition
Product visual
Features
Proof
Pricing
CTA
```

## Style

```text
Clean
Modern
Trustworthy
Structured
```

## Animation

Use:

* Product demonstrations
* Subtle section reveals
* UI state animations
* CTA feedback

# AI Product

## Priorities

```text

Output
```

# General Rule

The website category determines:

```text
Information hierarchy
Visual personality
Density
Interaction
Animation intensity
Typography
Color
```

Do not use the same design language for every category.
